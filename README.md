# Tennis league website kit

- `site/` is the live Men's Wednesday Night League site (fall 2026).
- `template/` is the same site with blank data for new leagues (see `template/SETUP-GUIDE.md`).
- `HANDOFF-GUIDE.md` explains the kit for whoever runs the next league.

No build step: open `site/index.html` or upload the folder to any static host.
All league content lives in `league-data.js`; edit it on the site's Manage tab and download, or edit by hand.
