# Flex Singles League website

Same site as the Wednesday league, set up for singles with one match per week
that the two players schedule themselves. Live sharing is on: every score and
change goes to the shared league server and shows up for everyone.

- Weeks start on Mondays. A match shows "This week" from Monday through Sunday,
  then moves to "Waiting for a score" on the home page if no result was entered.
- "Text Seth" / "Text Alegra" buttons on a match open a text with the week and
  who brings balls already typed.
- Ball duty was assigned so each player brings balls for about half of their own
  matches.

See the ? Help button on the site and the notes in the main README for everything else.
